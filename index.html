You don't install apps. You ask for one, and a model writes it.

An operating system written from nothing in Rust, for x86-64 PCs. An early test: it runs in QEMU and VirtualBox.

Download 0.1.0 Source on GitHub

What you can say to it today

I want a dice that rolls
A small app is written, run in a sealed box, and kept for next time.
draw a table of the planets
The table is drawn on the screen and kept as a document.
add a column with their moons
The same table, changed.
download example.com/prices.csv and open it
The file is fetched, kept on the disk and opened as a document you can change.

Download

boos 0.1.0 is an early test: a ready disk for VirtualBox and QEMU. Get it from the release page, which says how to start it.

The model needs a key of your own from OrcaRouter (the author's referral link, or orcarouter.ai). Pass on the download, not a used disk: it holds your locked key.

To build the newest code yourself, with Windows, Rust and QEMU:

git clone https://github.com/borisandreipavel-a11y/boos
cd boos
.\run.bat

Never run on real hardware yet. The README has the details and the limits. MIT or Apache-2.0.
